# Power BI Sales Dashboard

## Overview
This project is an interactive Power BI dashboard created to analyze sales, profit, category performance, and regional trends. It was built to demonstrate data cleaning, KPI tracking, data visualization, and business insight generation.

## Tools Used
- Power BI
- Excel
- DAX
- Power Query

## Key Metrics
- Total Sales
- Total Profit
- Profit Margin
- Top Performing Categories
- Regional Sales Trends

## Key Insights
- Phones generated the highest sales among product categories.
- Laptops contributed the highest profit in absolute terms.
- Some categories had strong revenue but lower profit margins.
- The dashboard helps identify high-performing and low-performing segments.

## 📁 Files in This Repository
